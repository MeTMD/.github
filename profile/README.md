## 项目简介

针对现有具身多智能体研究在三维动态环境适配不足、多智能体深度协作缺失及信息传递架构被动化的局限，结合数字文化产业对高沉浸、高智能交互技术的迫切需求，本研究聚焦三维具身多智能体的交互机制与协作规律展开系统探究。

以 Minecraft 为三维沙盒实验平台，选用 Voyager 等开源具身智能体，融合多模态大语言模型优化其语言交互与自主决策能力，构建 “基础生存协作 - 服务交互 - 复杂动态” 三类标准化实验场景，设计单智能体基础性能实验与多智能体协作实验，建立涵盖个体性能、交互效能、信息传递有效性的多维度评估指标体系。

实验结果表明：优化后的单智能体平均指令执行准确率达 82%，其性能显著受角色属性适配性、环境复杂度及指令复杂度影响，依赖语言交互与空间导航的角色表现更优；多智能体系统中，“规划者 + 执行者 + 协调者” 的专业化分工模式与网状交互结构适配性最佳，较随机分工协作效率提升 30% 以上，小规模智能体（3-8 个）在中低复杂度任务中协作完成率超 78%，群体协作呈现 “协作默契提升 - 群体规范形成” 的演化特征，但存在路径依赖风险。

本研究填补了三维动态环境下具身多智能体交互的理论空白，完善了 “玩家发起 - 智能体传递 - 群体响应” 的主动式信息传递架构理论，为游戏 NPC 智能化开发、虚拟服务场景优化等提供了可落地的技术参考，对推动具身智能技术向虚拟文旅、在线教育等领域延伸具有重要意义。
